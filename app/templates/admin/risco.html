Prazo e risco

Como a cor da coluna Prazo é calculada

Cada vínculo exibe um selo com a posição no prazo do programa (mês X de Y), colorido pelo risco. A regra vigente:

  • vermelho (alto) — um marco de tipo crítico está vencido e não concluído, ou já decorreu mais de {{ config.limiar_alto }}% do prazo do vínculo.
  • amarelo (médio) — decorreu mais de {{ config.limiar_medio }}% do prazo.
  • verde (baixo) — todo o resto.

Tipos de marco críticos neste momento: {% if config.criticos %} {% for t in config.criticos %}{{ tipo_label[t] }} {% endfor %} {% else %} nenhum — o risco depende só do tempo decorrido. {% endif %}

Modelo Multidimensional de Risco de Prazos (0–100)

Além do selo rápido de prazo, o ARIADNE calcula um índice composto de 0 a 100 pontos baseado na metodologia Earned Schedule (ES) combinada com alertas precoces (Early Warning System - EWS). O índice avalia a execução física ponderada das tarefas, ritmo de avanço temporal (SPI(t) e TSPI), severidade dos atrasos, marcos críticos com retrabalho e o engajamento do orientando em reuniões e entregas.

  • Pesos do modelo (soma = 100): Atrasos e severidade: {{ config.peso_atraso }} pts · Ritmo Earned Schedule: {{ config.peso_ritmo }} pts · Marcos críticos e retrabalho: {{ config.peso_criticos }} pts · Engajamento e assiduidade: {{ config.peso_assiduidade }} pts.
  • Cortes de classificação: Baixo: pontuação < {{ config.nota_risco_moderado }} · Moderado: ≥ {{ config.nota_risco_moderado }} · Alto: ≥ {{ config.nota_risco_alto }} · Crítico: ≥ {{ config.nota_risco_critico }} (marcos críticos vencidos pelo orientando ou prazo final expirado com tarefas pendentes ativam piso crítico automático).

O percentual decorrido é contado entre a data de início e o fim previsto do vínculo. Vínculo sem fim previsto não tem percentual: nele a cor depende apenas dos marcos críticos, e o selo diz "prazo não definido". A cor é recalculada a cada exibição — alterar os parâmetros vale imediatamente para todos os vínculos.
