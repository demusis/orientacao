Prazo e risco

Como a cor da coluna Prazo é calculada

Cada vínculo exibe um selo com a posição no prazo do programa (mês X de Y), colorido pelo risco. A regra vigente:

  • vermelho (alto) — um marco de tipo crítico está vencido e não concluído, ou já decorreu mais de {{ config.limiar_alto }}% do prazo do vínculo.
  • amarelo (médio) — decorreu mais de {{ config.limiar_medio }}% do prazo.
  • verde (baixo) — todo o resto.

Tipos de marco críticos neste momento: {% if config.criticos %} {% for t in config.criticos %}{{ tipo_label[t] }} {% endfor %} {% else %} nenhum — o risco depende só do tempo decorrido. {% endif %}

O percentual decorrido é contado entre a data de início e o fim previsto do vínculo. Vínculo sem fim previsto não tem percentual: nele a cor depende apenas dos marcos críticos, e o selo diz "prazo não definido". A cor é recalculada a cada exibição — alterar os parâmetros vale imediatamente para todos os vínculos.
